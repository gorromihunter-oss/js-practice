# Recipe Finder

A simple web app that searches for recipes by ingredient using TheMealDB API.

## Built with
- HTML
- CSS
- JavaScript (fetch, async/await)

## What I practiced
- Fetching data from a public API
- Handling errors and empty results
- Dynamically creating elements with JavaScript
- Splitting code into separate HTML, CSS, and JS files

## How to run
Open `day16-18.html` in your browser.
