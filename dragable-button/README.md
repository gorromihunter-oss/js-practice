# Draggable Button

A simple button you can click and drag around the page.

## Built with
- HTML
- CSS
- JavaScript (Pointer Events)

## What I practiced
- Using `pointerdown`, `pointermove`, and `pointerup` events to track dragging
- Calculating offsets so the button doesn't "jump" when you start dragging it
- Using `setPointerCapture` / `releasePointerCapture` to keep tracking the pointer smoothly
- Combining drag behavior with a normal `click` event on the same element

## How to run
Open `practice8.html` in your browser, click and hold the button, then drag it anywhere on the page.
