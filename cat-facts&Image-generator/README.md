# Cat Facts & Random Image

Click one button for a random cat fact, another for a random image.

## Built with
- HTML
- CSS
- JavaScript (fetch, async/await)

## What I practiced
- My first use of `fetch`, `await`, and unpacking a JSON response
- Learning that not every API call needs `.json()` — setting an `<img>`'s `src` directly works for images
- Using `Date.now()` to force a fresh image each click instead of a cached one
- Basic loading-state text on a button while a fetch is in progress

## How to run
Open the HTML file. Click "New Fact" for a cat fact, or "New Image" for a random photo.
