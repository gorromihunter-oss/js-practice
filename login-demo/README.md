# Login Demo

A fake login form that shows a loading state, then displays whatever you typed.

## Built with
- HTML
- CSS
- JavaScript (DOM manipulation)

## What I practiced
- Grabbing multiple different input types (text, password, checkbox) with `querySelector`
- Reading a checkbox's state with `.checked`
- Faking a "logging in" delay with `setTimeout`
- Wrapping setup code in `DOMContentLoaded` so it only runs once the page is ready

## How to run
Open the HTML file, type anything into the fields, check or uncheck "Remember me", then click Login to see a fake loading sequence.
