# GitHub User Lookup

Type a GitHub username and fetch their public profile info (follower count).

## Built with
- HTML
- CSS
- JavaScript (fetch, async/await)

## What I practiced
- Building a fetch URL dynamically from user input (template literals)
- Checking `response.ok` and throwing custom errors for invalid usernames
- Handling both network failures and "successful but not found" API responses
- Showing a loading state while waiting for the fetch to resolve

## How to run
Open the HTML file, type a real GitHub username (e.g. `octocat`), and click "GitHub".
