# To-Do List

A simple to-do list app — add tasks, delete individual tasks, use Enter or a button to submit.

## Built with
- HTML
- CSS
- JavaScript (DOM manipulation)

## What I practiced
- Creating elements dynamically with `createElement` and `appendChild`
- Giving each task its own delete button, scoped correctly to just that item
- Supporting both a click and the Enter key to add a task
- Clearing and refocusing the input field after adding a task

## How to run
Open the HTML file, type a task, press Enter or click Send, then click Delete to remove any task.
