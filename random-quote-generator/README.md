# Random Quote Generator

Click a button to fetch and display a random quote and its author.

## Built with
- HTML
- CSS
- JavaScript (fetch, async/await)

## What I practiced
- Fetching from a public API that needs no signup or API key
- Handling different failure statuses with custom error messages
- Reusing the same loading/fetch/error pattern from earlier projects on a new API

## How to run
Open the HTML file and click the button to get a new quote.
